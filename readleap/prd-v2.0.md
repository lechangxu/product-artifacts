# ReadLeap Max PRD 摘编（v2.0）

> 原始版本：V2.0，2026-04-11，状态 Ready for Beta Execution。
> 本文为公开版摘编：保留问题定义、用户、核心流程与关键决策，删去内部实现细节与商业条款。

## 1. 一句话定义

ReadLeap Max 是一个「语境化间隔重复」英语学习系统：用 AI 生成含目标词的文章，
再用记忆算法调度复习时机，把单词记忆放进真实语境里完成。

## 2. 问题

| 方法 | 留存率 | 缺陷 |
| :---- | :---- | :---- |
| 死记硬背 / 抄写 | < 5% | 无语境，孤立记忆 |
| 背单词 App（选择题形态） | 30-40% | 会做题，放进真实阅读仍不认识 |
| 原版书泛读 | 高但低效 | 生词分布随机，学习路径不可控 |

机会窗口：可理解性输入（i+1）+ 主动提取练习两套认知科学结论已成熟；LLM 让「按用户词汇量
实时生成语境文章」变得可行；本地算力让数据不必离开设备。

## 3. 用户

- **Persona A：高中生，CEFR B1**。痛点是高考词汇量不足、背了忘。典型动作：晚自习前
  15 分钟复习到期词；输入感兴趣话题，系统生成含待复习词的文章；答错时拿到提示而非答案。
- **Persona B：职场人士，CEFR A2→B1**。痛点是工作邮件词汇不够。典型动作：通勤时复习
  商务词；把邮件里的生词导入，生成职场语境例句；用 TTS 听慢速发音。

## 4. 核心流程

1. **导入生词**：手动输入 / 批量粘贴 / 考纲词库对接。
2. **生成文章**：按用户词汇画像与兴趣话题生成阅读材料，目标词必须物理出现在正文里。
3. **测验与反馈**：阅读理解与词汇题，主观题给苏格拉底式提示，不直接给答案。
4. **记忆调度**：按记忆算法计算每词的下次复习时间，到期词进入下一轮文章生成。

## 5. 目标与非目标（MVP）

**必须完成**

- 完整学习循环：导入 → 生成 → 测验 → 调度。
- 数据持久化：单词、学习历史、每日待复习量。
- 基础界面：桌面与移动端自适应的网页端。
- 安全层：内容过滤。

**V2 再做**

- 多用户账户体系、付费订阅集成、移动 App、社交与排行榜、教师后台。
- 模型范围：只支持本地推理与本地语音合成，不接入外部闭源大模型。

## 6. 关键决策

1. **语境优先于词表**：不追求覆盖最多单词，追求「这个词出现在用户看得懂的文章里」。
2. **AI 生成 + 机器校验**：文章必须满足目标词留存率与长度下限，否则整篇作废重写 ——
   把「生成质量」从主观判断变成可校验的规则。
3. **提示而非答案**：测验环节的价值在提取练习，直接给答案会让练习失效。
4. **本地化为差异化**：推理与语音都在本地，隐私与成本同时成立。

## 7. 早期商业假设（已过时，仅存档）

- 定价假设：免费 MVP → 邀请制早鸟 → 订阅制。
- 目标：上线后 3 个月内验证付费意愿，成本以推理与托管为主。
