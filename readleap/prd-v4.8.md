# ReadLeap Max PRD 摘编（v4.8）

> 原始版本：V4.8，2026-06-14。源文档约 1400 行，本文按公开口径摘到 200 行以内：
> 保留产品定位、用户、核心机制、生成约束、指标与路线图；删去接口契约、数据库结构与提示词全文。

## 1. 产品定位

一款 AI 驱动的英语阅读学习系统：用「主动回忆 + 间隔重复 + 语境沉浸」三件事解决背单词留存率低的问题。

| 维度 | 做法 |
| :---- | :---- |
| 记忆调度 | FSRS 算法按每词计算下次复习时间，而不是固定间隔 |
| 内容生成 | 按用户词汇画像与话题实时生成文章，目标词必须出现在正文里 |
| 难度控制 | Lexile 框架下的 i+1 舒适区边界，配合 CEFR 双维度 |
| 反馈方式 | 苏格拉底式引导提问，不直接给答案 |

竞品对照：传统背单词 App 用预设题库 + 固定间隔 + 直接显示答案；本产品用生成内容 + 自适应调度 + 引导式反馈。

## 2. 用户画像

| 用户类型 | 词汇量区间 | 核心痛点 | 对应词库 |
| :---- | :---- | :---- | :---- |
| 初中生 | 800–1500 | 课标词汇记不牢 | 初中课标（约 1600 词） |
| 高中生 | 1500–3500 | 高考词汇量大、遗忘快 | 高中课标（约 3500 词） |
| 大学生 | 3500–5500 | 备考 CET-4/6 | 四六级词库 |
| 留学备考 | 5000+ | 托福/雅思高频词 | 留学词库 |
| 进阶学习者 | 8000+ | 学术词汇 | GRE 词库 |
| 职场人士 | 不定 | 缺真实语境、难坚持 | 自定义词库 |
| 语言爱好者 | 不定 | 传统方法效率低 | 自定义词库 |

## 3. 典型流程

登录 → 检查会话计数 → 选择模型 → 按词汇库与话题生成文章 → 苏格拉底式测验与即时反馈 →
结算积分 → 到期词由 FSRS 调度器带回下一轮生成。

场景分支表：

| 场景 | 触发条件 | 系统响应 |
| :---- | :---- | :---- |
| 新词导入 | 用户输入 / 粘贴单词 | 给出释义、例句、发音 |
| 会话学习 | 用户选话题开始 | 生成文章 + 测验 + 引导式反馈 |
| 智能复习 | FSRS 到期 | 把待复习词编织进新主题文章 |
| 挫败干预 | 连续答错 + 停滞过久 | 降级到显示原文翻译 |

## 4. 三个旗舰功能

### 4.1 词汇认知画像评测

- **两阶段自适应测评**：第一阶段快速定位能力区间，第二阶段按维度均衡出题，逐维诊断。
- **输出不是分数而是一份画像**：词汇量估计 + 置信区间 + 每词的掌握状态。
- **题量与终止规则可计算**：标准模式 25 题；题库轮换与曝光控制保证重测有差异。

### 4.2 自适应学习会话

- 文章由目标词、用户兴趣、难度等级三者共同约束生成。
- 测验难度随答题表现动态升降，避免「太难放弃 / 太简单无增益」。
- 会话结束写回词级长期记忆画像：遗忘概率、记忆置信度、学习效率、语义稳定度、反应流畅度。

### 4.3 自动掌握判定（v4.8 重构）

把「这个词算不算学会了」从单一阈值改成**五因子证据模型**：

| 因子 | 作用 |
| :---- | :---- |
| 能力先验 | 测评给出的整体水平 |
| 词频先验 | 高频词更可能先掌握 |
| 置信度折扣 | 证据少时压低评分，不给虚高结论 |
| 词项特征 | 词长、抽象度、似曾相识的干扰词 |
| 用户历史 | 复习与答对记录 |

输出三档：`auto_master`（自动判定掌握）/ `needs_calibration`（需校准）/ `to_study`（继续学）。
配合考试核心词的保守惩罚、校准题量提升到 24 题（每档 ≥6）、抽样 500 次，以及阈值版本化
（`rule_version`）—— 规则变了可回滚，判定可追溯。

## 5. 生成约束（防幻觉体系）

系统把「生成质量」拆成可校验的规则，而不是靠人工逐篇看：

1. **关注点分离**：PRD 定义约束与验收法则；提示词注册表维护精确英文 prompt；代码库为执行唯一真相源，1:1 映射。
2. **写作者必须物理写入**：目标词必须真实出现在正文里，不允许只在结构化字段里返回；文章长度有硬性下限。
3. **审核者必须物理核验**：像正则匹配一样对正文做子串校验，缺一个目标词或篇幅不足就无条件驳回。
4. **判卷不泄露答案**：除保底模式外绝不直接给答案；判卷依据 100% 来自原文，不引入外部知识。
5. **批改不捏造错误**：句子本身正确就保持原样，禁止为了显得有用而改。

## 6. 成功指标（当时设定，非实测）

| 指标 | 目标值 | 周期 |
| :---- | :---- | :---- |
| DAU/MAU | > 20% | 月度 |
| 平均会话时长 | > 15 分钟 | 周度 |
| 7 日词汇掌握率 | > 60% | 周度 |
| NPS | > 50 | 月度 |

监控：接口错误率 > 5% 触发 P1；FSRS 计算失败每分 > 10 次、LLM 网关超时 > 30s 触发 P2。

## 7. 路线图

| 阶段 | 时间 | 重点 |
| :---- | :---- | :---- |
| Phase 1 MVP | 当时阶段 | 核心闭环跑通：测评、自适应会话、引导式测验、FSRS 记忆引擎；测验难度动态升降与跟读练习列为最高优先 |
| Phase 2 Growth | 2026 Q3 | 角色扮演、作文批改、搭配学习；测评引擎演进与多音色为低优储备 |
| Phase 3 Scale | 2026 Q4 | 移动端、学习社区、企业版 |

一条产品判断写死在文档里：积分机制的开发门槛是**真实活跃用户 ≥ 10**，不到不启动 ——
先用留存验证价值，再上激励系统。
